# Grill Me: Investment Research

[English](README.md) · **简体中文**

一个投资想法，能经得住多少个“为什么”？

这个 Agent Skill 通过一次一个问题的对话，帮助你明确研究目标、已有判断和证据缺口，最终交付一份可以继续研究的 Research Brief。每个问题附带建议回答，方便你赞同、修改或提出不同判断。

## 会问到什么

- 研究目的：开始研究、跟踪持仓、学习、验证或复查。
- 时间范围：短期事件、中期经营变化或多年趋势。
- 分析范围：市场、地域、竞争对象。
- 分析层次：宏观、行业、供应链和公司。
- 已有知识：已知事实、当前假设和仍需验证的部分。
- 交付形式：研究备忘录、估值模型、会议材料等。
- 风险：反方观点、遗漏信息，以及什么证据会改变判断。

Agent 应当读取能够自行找到的资料，再提出需要你回答的问题。

## 安装与使用

将 [SKILL.md](SKILL.md) 放入 `~/.claude/skills/grill-me-research/SKILL.md`，由兼容 Agent Skills 的客户端加载。也可以通过支持 Skill 上传的客户端安装。

```text
使用 $grill-me-research 帮我明确英伟达数据中心业务的研究问题。
我希望形成一个十二个月的研究判断，逐个问题讨论。
```

最终 Research Brief 包含研究对象、目标、期限、比较维度、分析重点、当前假设、已知信息、资料缺口、交付格式和主要风险。涉及公司的例子用于展示提问方式，判断需要根据当前资料重新验证。

Skill 的执行内容位于单个 `SKILL.md`，没有额外脚本依赖。适合研究员、学生、个人投资者和准备投资讨论的人。
